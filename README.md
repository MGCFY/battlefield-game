# 战场沙盘策略游戏

同一套沙盘规则的三份实现：

| 文件 | 说明 |
|------|------|
| **`battlefield-v2.html`** | ⭐ **视野版网页（最新，推荐）**——战争迷雾 + 昼夜 + 10 兵种积分部署 + 键盘操作 |
| **`battlefield-v2.cpp`** | ⭐ **视野版 C++（最新）**——与网页版规则完全一致的控制台移植 |
| `battlefield.html` | 基础网页版——无迷雾，规则与 C++ v1 版一致 |
| `battlefield.cpp` | C++ 控制台版（v1 规则）——需本地编译 |

三份都是单文件、零依赖，网页版双击即可游玩。

# 一、视野版（battlefield-v2.html）

## 快速上手

1. 浏览器打开 `battlefield-v2.html`；
2. **部署阶段**：红、蓝双方各用 **1000 积分**自由采购兵团（点"推荐配置"可一键填好）；
3. 开局后：**点击己方兵团 → 点指令按钮 → 按棋盘高亮点击目标格**；`Esc` 取消当前操作（不消耗行动）；
4. 每个兵团每回合只能执行 **一项** 指令，全部安排完点"结束回合"。

## 新增玩法总览

### 1. 积分部署（1000 分 / 方）

| 兵种 | 单价 | 移动 | 白天视野 | 备注 |
|------|-----:|-----:|--------:|------|
| 步兵 | 1/名 | 1 | 2 | 可休整；可修筑工事/防空地堡 |
| 骑兵 | 4/名 | 3 | 3 | 可拆毁防御工事 |
| 轻炮兵 | 5/名 | 1 | 3 | 远程打击，可攻击休整目标 |
| 侦察兵 | 5/名 | 1~3 | 6 | 永远算"小兵团"；不能进攻；带照明弹/烟雾弹 |
| 重炮兵 | 10/名 | 1 | 3 | **仅休整时**可打击，射程 8 格 |
| 坦克 | 50/辆 | 2 | 4 | 远程每辆击杀 20 人；3 点耐久 |
| 喀秋莎 | 50/辆 | 2 | 4 | 3×3 面杀伤；**无休整**；需先装填弹药 |
| 侦查机 | 100/架 | 2 | 3 | **空中**：不可被看见/攻击；带照明弹/烟雾弹 |
| 轰炸机 | 200/架 | 2 | 3 | **空中**；携带 1 发导弹，回大本营可补充 |

> 推荐配置（990 分）：步兵 400 · 骑兵 30 · 轻炮兵 20 · 侦察兵 4 · 重炮兵 10 · 坦克 2 · 喀秋莎 1 · 侦查机 1

### 2. 昼夜与视野

- 每 **10 回合**昼夜互换，20 回合 = 1 天（1~10 白天、11~20 夜晚、21~30 白天…）。
- **夜晚**：除侦察兵视野 **-2**，其余所有兵团（含飞机）视野 **-1**。
- **战争迷雾**：视野之外的**地形、敌方兵团、防御工事、防空地堡**一律不可见。
  - 头顶"记忆地形"勾选（默认开）表示"已探索过的地形以灰调保留"，取消勾选则严格只显示当前可见地形。
  - **视野内**的敌方兵团可看出是否处于**休整**（视野外则完全不可见）。
  - **敌方空中单位永不可见**，仅当它距我方任一兵团 ≤3 格时，右侧弹出空中威胁警报。
  - **照明弹**覆盖范围内（3×3）的所有兵团**全图可见**，双方都看得见。
- **视野是全方共享的**：侦察兵看到的 6 格视野，前排轻炮兵就能打 4 格外的目标——这是"侦察—火力"协同的核心。
- **距离口径**：全游戏所有距离一律使用**曼哈顿距离（菱形）**——视野、射程、雷达、投掷、合兵相邻等全部一致。

### 3. 情报：只显示兵团大小

视野内的敌方**地面**兵团只暴露规模，不暴露兵种与兵力：

| 规模 | 判定（该格积分总和 = Σ 数量×单价） |
|------|-----------------------------------|
| **小** | < 50（**侦察兵永远算小**，哪怕 100 名侦察兵 = 500 分） |
| **中** | 50 ~ 199 |
| **大** | ≥ 200 |

### 4. 大本营雷达

我方大本营 **5 格（曼哈顿距离，菱形）**范围内遭到敌方炮兵/载具（地面或空中，含轰炸机导弹）打击时，
会通报来袭火力**距被打击地的格数**——这是定位敌方远程单位的唯一线索。

### 5. 移动

| 兵种 | 规则 |
|------|------|
| 步兵 / 轻炮兵 / 重炮兵 | 每次 1 格 |
| 侦察兵 | 1~2 格；可奔袭 **3 格**，但下个回合不能移动 |
| 骑兵 | 最多 3 格（无副作用） |
| 载具（坦克/喀秋莎/侦查机/轰炸机） | 最多 2 格 |

- 地面单位不能穿越兵团、禁地、无桥河面（过河必须走桥）；**空中单位可飞越一切地形**。
- **己方看不见的敌军不会挡路**——走进去了才会触发遭遇战（迷雾中的伏击）。
- 炮兵/侦察兵走人有敌军的格子会被全歼，棋盘会以红色边框 + 提示预警。

### 6. 战斗结算

**近战**（移入敌军格，逐轮消耗直至一方全歼）：

| 交战 | 每回合损耗 |
|------|-----------|
| 步兵 : 骑兵 | **1 : 3** |
| 骑兵 : 坦克/喀秋莎 | **1 : 10** |
| 步兵 : 坦克/喀秋莎 | **1 : 20** |
| 同兵种 | 1 : 1 |

- **侦察兵无法进攻**（不会显示为攻击目标）；**炮兵/侦察兵遭遇有近战能力的兵团 → 被全歼**。
- 减损（可叠加）：**休整 ×0.5**、**高地 ×0.5**、**工事上的被进攻方 ×0.5**、**载具再乘 耐久/3**。

**远程打击**（打击方格子，摧毁该格防御工事）：

| 单位 | 射程 | 每单位杀伤 |
|------|------|-----------|
| 轻炮兵 | 未休整 4 / 休整 5 | 未休整 3 人 / 休整 5 人 |
| 重炮兵 | 8（**仅休整可打**） | 8 人 |
| 坦克 | 未休整 3 / 休整 4 | 每辆 20 人 |
| 喀秋莎 | 4 格内选中心点 | 每辆 30 人（中心 50%，其余 50% 在周围 8 格随机结算） |

- 高地一律 **+1 格**射程。
- 打击目标**只需在射程内**（曼哈顿距离）——**可盲打**，无需目标在己方视野内。
- 目标侧的减免同样生效：休整 ×0.5、高地 ×0.5、防空地堡 ×0.5，最终四舍五入。
- **喀秋莎**无休整状态，须先花一回合"装填弹药"，之后每次打击后需重新装填。

### 7. 工事与防空地堡

| 建筑 | 建立 | 效果 |
|------|------|------|
| 防御工事 `#` | 休整步兵，相邻格，消耗一回合 | 其上的**被进攻方**近战减损一半；骑兵可拆毁；被炮兵/载具打击时被摧毁 |
| 防空地堡 `堡` | 休整步兵，**在自身格**，消耗一回合 | 格上单位受炮兵/载具打击**损耗减半**；承受 **3 次打击**后永久失效，且该格**不可再建** |

### 8. 照明弹 / 烟雾弹 / 导弹

| 装备 | 携带者 | 规则 |
|------|--------|------|
| 照明弹 | 侦察兵、侦查机、轰炸机 各 1 发 | 投向视野内任一格，3×3 **照明区**持续 5 回合，区内兵团全图可见 |
| 烟雾弹 | 同上 | 投向视野内任一格，3×3 **烟幕**持续 5 回合：区内非空中单位视野降为 **1 格**；**区外无法窥视区内**，仅同处烟幕中的单位可互相看见 |
| 导弹 | 轰炸机 1 发 | 投向轰炸机周边 **3 格（曼哈顿）**内任一格（**可盲打**），**下一回合命中**；该格无防空地堡则**格上所有单位（含友军）全歼**，有地堡则损耗减半 |

- **空中载具飞回己方大本营**时自动补给照明弹、烟雾弹，轰炸机额外补 1 发导弹。
- 导弹落点 ⊕ 预警标记：**发射方始终可见**；防守方仅在落点处于己方大本营雷达范围（5 格，曼哈顿菱形）内时可见。
- 空中单位的照明弹/烟雾弹对空投掷与地面相同（区域生效于地面格）。

### 9. 耐久

坦克与喀秋莎各有 **3 点耐久**：被**炮兵或地面载具**打击掉 1 点，归零即毁。
剩余 n 点时，近战损耗乘 **n/3**（即 2 点耐久只承受 2/3 损耗）。

### 10. 胜负

- **地面兵团**占领对方大本营（第 3 行第 3 列 / 第 17 行第 17 列）即获胜（空中单位不能占领）；
- 一方**再无任何地面兵团**（只剩飞机或全灭）即判负。

### 规则细节的实现取舍

原规则中少数表述存在歧义，v2 的实现方式如下（与前两版保持一致的沿用 v1 结论）：

1. **"损耗 1:3 / 1:10 / 1:20"** 按"每回合双方各自的伤亡数之比"实现，逐轮同时结算直至一方全歼。
2. **减损为小数累积**：每回合产出可能是 0.5 人，累积到 1 才真的扣人。
   这样"休整减半"在基础损耗为 1 时也真实生效（否则四舍五入后等于无效）。
3. **"防御工事"** 解释为保护**处于工事上的被进攻方**（主动进攻者不享受）。
4. **"炮兵或侦察兵遭遇步兵或骑兵被全歼"** 推广到"遭遇任何有近战能力的兵团"，即炮兵/侦察兵一旦进入近战即被歼灭。
5. **距离口径** 全游戏取曼哈顿距离（菱形）：视野、射程、雷达、投掷、合兵相邻等全部一致。
6. **"记忆地形"** 为可选项（默认开）：关闭后地形严格只在当前视野内可见。地形的静态性使得记忆不影响平衡，只影响手感。
7. **休整情报**仅在视野内可见（视野外的敌方整备状态完全隐藏）。
8. **空中单位不阻挡地面单位通行**（它飞在空中），也不会被地面近战波及。
9. **侦察兵走 3 格的疲劳**用疲劳计数实现：奔袭当回合结束置 2，之后每个自己回合结束递减，疲劳期间仅禁止移动。
10. **喀秋莎弹药**：装填消耗一回合，装填后可随时打击，打击一次后需重新装填。
11. **导弹预警**：发射方始终可见自己的导弹落点 ⊕；防守方仅在落点进入己方大本营雷达范围（5 格）时可见，与日志分方策略一致。

2. **侦察兵移动简化**：跳过"选择步数"中间步骤，直接选落点；落点在 **3 格（奔袭）**时

   - 支持 WASD + Enter 的模式：移动、打击、分兵摆放、修筑/摧毁/拆毁工事、防空地堡、
     照明弹/烟雾弹、导弹。
4. **合兵保持原交互**（鼠标选择目标），本轮不做改动。

# 三、C++ 版编译与运行

## 3.1 视野版 C++（battlefield-v2.cpp，推荐）

与网页版 v2 **规则完全一致**的控制台移植：战争迷雾、昼夜、9 兵种 1000 积分部署、
打击脱敏战报（只报消灭人数/载具耐久/规模变化）、分方战报日志、喀秋莎面杀伤、
延迟导弹、防空地堡、照明弹/烟幕、大本营雷达、上帝视角、桥梁直行格生成。

```bash
g++ -std=c++17 -O2 -o battlefield-v2 battlefield-v2.cpp
./battlefield-v2
```

> 项目目录内已附带编译好的 **`battlefield-v2.exe`**（GCC 16.2.0、`-Wall -Wextra` 零警告编译通过），
> 双击或在终端直接运行即可。若 Windows 应用控制策略拦截未签名 exe，请自行用上述命令重新编译，
> 或在系统提示中选择"仍要运行"。

### 操作方式（控制台）

1. **部署**：输入「编号 数量」采购兵种，`r`=推荐配置，`c`=清空，`ok`=确认（红蓝各 1000 分）；
2. 开局后输入**军团编号**选中兵团（如 `1`），再输入**指令编号**执行；
3. 各指令按提示输入坐标「行 列」（1~20，`0` 取消且不消耗行动）；
4. 全局命令：`e`=结束回合、`v`=切换视角（自动/红/蓝/上帝）、`m`=记忆地形开关、
   `n`=重新开局、`q`=退出、`0`=取消选择。

> 视野版 C++ 与网页版差异仅为交互方式（网页用鼠标/WASD，控制台用坐标输入），
> 全部规则结算逻辑（含小数累积损耗、脱敏战果、分方日志、导弹预警可见性）保持一致。

# 四、通用规则（三版共享）

- **棋盘**：20×20，地形随机，比例 禁地:高地:平地 = **1:2:7**（40:80:280 格）。
- **颜色**：平地=绿，高地=白，河流=蓝，禁地=红，桥=黄。
- **河流**：一条自上而下蜿蜒、四方向连通、不自交的河流，河上恰好 **3 座桥**；
  禁地与无桥河面不可驻扎、不可通行（空中单位除外）。
- **大本营**：红方第 3 行第 3 列、蓝方第 17 行第 17 列，强制高地，周围一圈无河无禁地。
